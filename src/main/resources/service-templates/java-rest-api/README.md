## Running Locally

Prerequisites: JDK 21 and a running Docker runtime, which provides the local
PostgreSQL database and the database for tests.

```sh
./gradlew bootRun   # start on http://localhost:8080 (starts PostgreSQL with Docker Compose)
./gradlew test      # run the tests against PostgreSQL in a container
./gradlew build     # compile, test, and package
```
